# 從 CTF 到跨國開源協作：我為什麼踏入 BugTraceAI

一開始接觸資訊安全的時候，我一直覺得 CTF（Capture The Flag，奪旗賽）已經是很猛、很頂的事情了。

但在過去這一兩年，參加了大大小小的資訊安全活動之後，我學到的早就不只有攻擊與防禦。

尤其現在 AI Agent 的時代來了，我開始想一件事：

**傳統的 CTF，真的還有存在的必要嗎？**

我之前看到國外有專門讓 AI Agent 參與的 CTF 競賽。那時候就覺得，我們是不是不應該只把 AI Agent 當成協助開發或維護資訊安全的工具？

如果它能更深入地參與資安研究，未來又會變成什麼樣子？

這些想法，也是我後來踏入 BugTraceAI 跨國協作的原因之一。

## 我是怎麼接觸到 BugTraceAI 的？

一開始，我是在社群媒體上關注到這個團隊。

當時注意到他們的執行長，曾經在香港分享過資訊安全和 AI Agent 相關的議題，也參與過一些活動。

後來因緣際會，我有機會跟這位執行長聊聊。

我也直接跟他說，因為我現在還是大學生，不可能一直把重心放在這個專案上。除了學校的事情，我自己還有一堆比賽跟論文的壓力，在後面逼著我繼續往前走。

其實一開始，我真的沒抱太大的希望。

我想說，這種那麼頂尖的團隊，應該不會收留一個英文不是很好、也不是什麼頂尖名校出身的學生吧？

結果後來，執行長告訴我，他們剛好也缺資訊安全相關的開發者。

在我積極爭取之下，終於得到一次很難得的機會：協助尋找 BugTraceAI 系統裡的 Bug，以及需要調整、改善的地方。

## 然後，我遇到了一位西班牙的電神

喔對，我好像忘記介紹我的協作夥伴了。

一位來自西班牙的電神。

有多電？我得知他是哈佛畢業的時候，真的不知道該開心還是難過。

開心的是，我竟然有機會跟這麼強的開發者合作。

難過的是，我心裡一直在想：

**他會不會覺得我太爛啊？**

不過，在跟他討論過幾次專案、實際一起協作之後，我發現他是一位很好的前輩。

不只是技術能力很強，也讓我有很多值得繼續學習的地方。

接下來我還是會繼續向他學習，也希望自己能持續為這個團隊的開發和維護出一份力。

## 謝謝願意給我機會的人

這一路上，真的有太多人想感謝了。

謝謝執行長願意給我這次寶貴的機會。

謝謝那位哈佛畢業的超強開發者。沒有你的貢獻，我可能也不會有這一次的合作經驗。

也謝謝 BugTraceAI 的所有人，願意讓我參與這個團隊。

我會繼續努力，好好貢獻自己能做到的事情。>_<

這些只是我最近發生的事情裡，很小的一部分。
